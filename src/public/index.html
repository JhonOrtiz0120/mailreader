Buzones Configurados

Edite el arreglo JSON con la configuración de sus buzones. Las credenciales se envían de forma segura y se almacenan en el servidor.

Ver ejemplos de configuración (IMAP, Google, Microsoft)
IMAP Estándar:
{
  "id": "mb_1", "label": "Mi IMAP", "email": "ejemplo@imap.com", "provider": "imap", "active": true,
  "credentials": { "host": "imap.server.com", "port": "993", "user": "ejemplo@imap.com", "password": "123", "tls": true, "mailbox": "INBOX" }
}
Microsoft 365:
{
  "id": "mb_2", "label": "Mi Microsoft", "email": "facturas@microsoft365.com", "provider": "microsoft", "active": true,
  "credentials": { "tenantId": "...", "clientId": "...", "clientSecret": "...", "userEmail": "facturas@microsoft365.com" }
}
Google Workspace (Service Account):
{
  "id": "mb_3", "label": "Mi Google Workspace", "email": "facturas@gmail.com", "provider": "google", "active": true,
  "credentials": { "authType": "service_account", "userEmail": "facturas@gmail.com", "clientEmail": "cuenta@proyecto.iam.gserviceaccount.com", "privateKey": "-----BEGIN PRIVATE KEY..." }
}
